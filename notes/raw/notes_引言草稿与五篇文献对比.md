## 一、引言草稿（可放入论文第一部分）

近年来，人工智能技术的快速迭代推动算力需求呈现爆发式增长。据统计，截至2026年3月，全国日均词元（Token）调用量已超过140万亿，较2024年初增长逾千倍（《瞭望》新闻周刊，2026年第18期）。在"人工智能+"行动上升为国家战略的背景下，各地方政府纷纷将算力基础设施建设列为产业竞争的新赛道。据国海证券2026年研报统计，全国36省及重点城市2026年政府工作报告中，"人工智能"一词累计出现160次，"算力"出现63次，各省在战略性新兴产业布局上呈现高度同构。截至2026年3月底，全国已有20余个省市推出算力补贴政策，多地竞相发放"算力券""模型券"以争夺AI企业资源。

然而，政策热潮之下结构性问题正在浮现。《瞭望》新闻周刊2026年5月发表的深度调研报告系统披露了"算力招商内卷"现象：各地算力补贴标准差距悬殊——部分城市补贴比例高达50%并可多层级叠加；一些地方政府以民企牵头或国企购买服务器等方式绕开国家窗口指导建设算力中心，大量建成设施利用率不足三分之一（王圣志等，2026）。《经济日报》随后刊发评论明确警告"不能为了追求规模而盲目发展""避免一哄而上、低效内卷""避免资源浪费、产能过剩"（吴浩，2026）。事实上，地方政府围绕战略性新兴产业的同质化竞争并非新问题。已有研究指出，各地"千城一面"地布局新能源、电动汽车、芯片等产业，造成资源错配和市场分割，光伏行业主链环节产能过剩度已超过60%，部分智算中心利用率长期徘徊在25%~30%（黄群慧、叶其楚，2025；罗志恒、原野，2025；魏巍、曾铮，2025）。

然而，与政策实践的紧迫性形成鲜明对照的是，学术界的政策评估文献几乎全部集中于验证AI试验区政策的"正向效应"。自2019年国家人工智能创新应用先导区（NAIZ）和人工智能创新发展试验区设立以来，已有约10篇研究以该政策为冲击，使用双重差分法或双重机器学习方法，分别检验了其对研发投入与专利产出（刘华珂等，2024）、ESG表现（余少龙、石虹，2025）、企业就业（王晓丹等，2025）、产业链韧性（周十同等，2025）、新质生产力（任宇新、贺正楚，2025；胡曲应、王锐颖，2026）等积极结果的影响。这些研究的共同特征在于：它们共享"政策是否有效"的正向验证框架，尚未有文献在同一实证框架内讨论AI算力补贴政策在地方政府竞争下可能产生的差异化效果乃至效率损失。算力基础设施领域的实证研究同样以正向结论为主导——超算中心和智算中心的建成运营显著提升了企业全要素生产率（杨壮、吴福象，2025；许诺等，2025），但"算力内卷"这一正在演进的经济现象在这些研究中完全缺位。

在更深层的理论层面，政府补贴与创新质量的关系也并非简单的线性促进。最新研究发现，研发补贴可能使企业陷入"渐进式创新锁定"（孙雅慧等，2024）：企业既因技术路径依赖而倾向于在已有范式内改良，也因规避政策风险和迎合考核偏好而主动选择低风险的渐进式创新——这为审视算力补贴是否会诱发"建算力中心有余而产高质量AI专利不足"提供了直接对话接口。

上述三条文献脉络——AI政策效应评估、地方产业同质化竞争、补贴与创新质量——各自独立发展，彼此之间尚未形成交叉。而现实中正在发生的"算力招商内卷"恰恰位于这三者的交汇处。由此形成本文的核心研究问题：国家人工智能创新应用先导区的算力补贴政策，是否以及在多大程度上促进了AI领域的高质量创新？更重要的是，在地方政府同质化竞争的框架下，这一政策是否可能引发算力资源的重复建设与创新效率的分化？

本文的边际贡献体现在以下几个方面。第一，首次将"内卷式竞争"视角嵌入AI产业政策的因果效应评估，将现有文献"政策是否有效"的一维框架拓展为促进效应与效率损失并存的二维分析。第二，在理论层面构建了算力补贴的"地理集中—地理扩散"权衡框架：集中部署有利于知识溢出和规模经济，但可能加剧区域创新不平等；分散布局有助于降低地区差距和扩大技术可及性，却易诱发同质化投资和内卷式竞争。第三，在实证层面做出三项改进：使用CPC专利分类体系从全量专利中识别AI专利，限定因变量为AI领域的创新质量（新颖性、被引质量），以区别于已有研究使用全量专利的做法；引入在线招聘数据直接测度AI人才集聚，替代基于宏观统计的间接度量；首次考察NAIZ政策对非AI部门全要素生产率的溢出效应。第四，在政策层面，为中央近年多次部署的"综合整治'内卷式'竞争"提供来自AI算力领域的微观证据，也为从"补算力"向"拓场景"的政策转型提供实证依据。

### 2.2 详细对比分析

#### 刘华珂等（2024）—— 最直接的竞争与对话

| 维度               | 刘华珂等 (2024)                                                                                                                      | 本文                                                                                                 |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------- |
| **政策冲击** | 国家新一代人工智能创新发展试验区（共18个城市，2019—2022年分批设立）                                                                 | 国家人工智能创新应用先导区（NAIZ，2019年起分批推进）                                                 |
| **因变量**   | 研发投入、专利数量、专利被引量、**专利原创性**（基于前向引用的技术领域分散度）、**专利一般性**（基于后向引用的领域广度） | **AI专利新颖性**（CPC分类限定的AI领域内）、**AI专利被引质量**、**非AI部门TFP溢出** |
| **机制**     | 知识溢出（企业间地理距离与专利引用关系）、创新环境优化（数字基础设施、人力资本、金融发展）                                           | AI人才集聚（猎聘/智联招聘数据）、算力补贴强度（各地算力券政策标准）                                  |
| **政策含义** | 继续推进试验区建设，促进城市数智化转型                                                                                               | **双重效应**：区分集中式vs.分散式部署的效率差异，从"补算力"转向"拓场景"                        |
| **核心叙事** | 政策有效——试验区→创新↑                                                                                                           | 政策有条件有效——促进AI创新质量但地方同质化竞争导致效率损失                                         |

**本文的差异化操作**：

1. 使用CPC分类码从全量专利中筛选AI专利，而非使用全量专利。这一处理确保测量的是AI领域（而非一般制造业或传统IT）的创新质量。
2. 在因变量中加入非AI部门TFP溢出——刘华珂等只考察了被处理企业的自身创新产出，未考虑政策的空间外部性和跨部门溢出。
3. 叙事核心不同：刘华珂等证明"政策好"；本文回答"政策在什么条件下好、什么时候不好"。

#### 黄群慧、叶其楚（2025）—— 理论框架的引入者

| 维度               | 黄群慧、叶其楚 (2025)                                                                          | 本文                                                                                                                    |
| ------------------ | ---------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| **研究问题** | 制造业"内卷式"竞争的表现与形成机制                                                             | AI算力补贴是否也构成"内卷式"竞争的一个新场域？                                                                          |
| **分析框架** | SCP范式：宏观结构（内外需）→中观结构（平台/产业链）→微观结构（企业规模数量）→竞争行为与绩效 | 将SCP范式具体化：宏观（各省AI产业规划高度同构）→中观（NAIZ分批推进创造城市间竞争）→微观（企业算力使用成本与创新选择） |
| **方法**     | 定性理论分析                                                                                   | 定量因果推断（多期DID+事件研究法）                                                                                      |
| **覆盖领域** | 制造业全行业（钢铁、光伏、新能源汽车等）                                                       | AI算力基础设施（新兴产业、新基建）                                                                                      |
| **时间维度** | 多行业长周期趋势                                                                               | NAIZ政策实施前后（2015—2024年）                                                                                        |

**本文的差异化操作**：

1. 将黄群慧和叶其楚在制造业全行业层面的理论框架**下沉到AI算力这一具体新兴领域**，以微观数据检验其预设的机制。
2. 从定性分析转向定量识别——黄群慧和叶其楚文末指出需要后续定量验证，本文恰可填补这一空白。
3. 加入新的理论维度：算力不同于钢铁/光伏，它具有显著的**知识溢出和空间外部性**，因此"集中-扩散"权衡比传统产能过剩问题更复杂。

#### 孙雅慧等（2024）—— 创新质量的警示灯

| 维度                 | 孙雅慧等 (2024)                                                               | 本文                                                                       |
| -------------------- | ----------------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| **研究问题**   | 一般性研发补贴是否激励了渐进式而非突破式创新？                                | AI算力补贴是否促进了高质量AI专利，还是导致"建中心不产专利"？               |
| **因变量测度** | 专利摘要文本向量余弦相似度（与已往专利的相似程度越高→渐进式创新程度越高）    | AI专利被引质量（标准化前向引用次数）和AI专利新颖性（引用知识来源的分散度） |
| **补贴类型**   | 一般性研发补贴（年报中披露的政府补助）                                        | 特定于算力基础设施的补贴（通过NAIZ政策冲击识别）                           |
| **机制**       | 客观路径依赖（技术规模报酬递增+转换成本） + 主观策略动机（规避风险+迎合偏好） | AI人才集聚 + 地方补贴竞争（引入地方政府行为的制度维度）                    |
| **政策含义**   | 改革补贴评价体系、弱化路径依赖、外部监督                                      | 差异化部署（集中vs.扩散的权衡）、退出机制、从"补算力"到"拓场景"            |

**本文的差异化操作**：

1. 孙雅慧等关注**一般性补贴**→本文针对**算力专项补贴**，后者具有基础设施属性（不同于直接补贴企业R&D），其创新效应的传导机制更复杂。
2. 引入**地方政府行为维度**：孙雅慧等提到"迎合地方官员偏好"是被补贴企业的策略动机之一，但未直接检验地方政府竞争强度对创新质量的调节效应——本文将此设为核心调节变量。
3. 方法互补：可借鉴孙雅慧等的专利文本相似度指标作为稳健性检验中的替代因变量。

#### 许诺等（2025）—— 算力→TFP的最直接实证

| 维度               | 许诺等 (2025)                                               | 本文                                                            |
| ------------------ | ----------------------------------------------------------- | --------------------------------------------------------------- |
| **政策冲击** | 智算中心（以IDC许可证企业数据识别）                         | NAIZ政策（算力补贴+税收减免+数据便利化的一揽子政策）            |
| **因变量**   | 企业TFP（全要素生产率）                                     | AI专利新颖性、AI专利被引质量、非AI部门TFP溢出                   |
| **机制**     | "即时响应能力"+"价值挖掘能力"：算力外置+数据跨域流动→TFP↑ | AI人才集聚 + 算力补贴强度 + 地方同质化竞争度→创新质量分化      |
| **数据来源** | IDC许可证企业地理数据 + 上市公司财务数据                    | CSMAR + SIPO专利（CPC AI分类）+ AI岗位招聘数据 + 各省算力券政策 |
| **空间视角** | 数据跨域流动（算力迁出地/迁入地分析）                       | 相邻城市NAIZ政策的竞争 vs. 溢出效应                             |
| **政策含义** | 完善算力基础设施（电网、通信网络）                          | 从盲目扩建算力中心转向差异化部署和场景建设                      |

**本文的差异化操作**：

1. 许诺等考察的是**智算中心的商业运营**对TFP的影响，其IDC识别的是实际投入使用的数据中心——本文考察的是**政策性补贴激励**驱动的算力建设，二者形成了"市场供求两端"的互补视角。
2. 因变量从"生产效率"转向"创新质量"——TFP提升不等于创新质量提升。许诺等发现智算中心提升TFP，但这可能只是通过信息化效率改进实现的，未必意味着突破性AI技术创新。
3. 引入**竞争维度**：许诺等未考虑多城市同时建设智算中心的竞争效应——本文的空间DID设计正是为了捕捉这一点。

#### 杨壮、吴福象（2025）—— 方法最接近的参照系

| 维度               | 杨壮、吴福象 (2025)                                             | 本文                                                                  |
| ------------------ | --------------------------------------------------------------- | --------------------------------------------------------------------- |
| **政策冲击** | 国家超级计算中心（12个，2000—2023年陆续投入运营）              | NAIZ（多批次，2019年起）                                              |
| **方法**     | 多期DID                                                         | 多期DID + 事件研究法 + Sun & Abraham (2021)/C&S (2021) 异质性处理效应 |
| **因变量**   | 企业TFP                                                         | AI专利新颖性、AI专利被引质量、非AI部门TFP                             |
| **机制**     | 合作创新（联合专利申请） + 劳动力技能结构调整（高学历员工占比） | AI人才集聚（线上招聘数据） + 算力补贴竞争（省级补贴标准）             |
| **异质性**   | 发展禀赋/高技术行业/国企                                        | 城市算力集中度（集中vs.扩散）、省级竞争强度                           |
| **来源**     | 《经济学家》2025年第1期                                         | 投稿目标：《中国工业经济》《世界经济》等                              |

**本文的差异化操作**：

1. 政策冲击不同：超算中心是**科研公共品**（偏基础研究），NAIZ中的算力补贴是**产业政策工具**（偏应用和产业培育）——后者更容易诱发地方竞争。
2. 杨壮和吴福象只验证了"超算→TFP↑"的正向效应。本文在正向渠道之外，通过空间DID检验相邻NAIZ城市之间是否存在竞争损失。
3. 在方法上，本文的异质性处理效应检验（Sun & Abraham, Goodman-Bacon分解）对杨壮和吴福象使用的传统多期DID构成方法论改进。

### 2.3 综合交叉定位

                创新质量关注度高

                      │

                      │
      黄群慧等(2025)  │  许诺等(2025)  杨壮等(2025)
      制造业内卷SCP   │  智算→TFP↑    超算→TFP↑
                      │
                创新质量关注度低
                      │
                 ← 无内卷视角 ──│── 有内卷视角 →
                      │
                 ★ 本文位置：右上象限 +
                 首次同时兼顾创新质量
                 与内卷视角

**本文不重复任何已有研究的组合**：现有文献要么关注"AI政策→创新质量"但忽视内卷，要么关注"内卷竞争"但不涉及AI算力，要么关注"算力→TFP"但不讨论创新质量也不讨论内卷。本文在这三个维度的交叉处开辟了新空间。
