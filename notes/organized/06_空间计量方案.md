# 空间计量方案

## 为什么需要空间计量

多期 DID 默认一个城市的处理状态不会影响其他城市，但本文问题本身涉及空间互动：

- NAIZ 城市可能向周边城市产生知识溢出。
- 相邻 NAIZ 城市可能争夺同一批 AI 企业、人才和算力需求。
- 同省或相近城市的算力券、模型券和智算中心政策可能趋同，形成竞争效应。

空间模型应服务于 H2 和 H3 的理论问题，不能为了方法复杂而复杂。基准研究主线仍应是 DID、竞争交互项和距离带宽/空间暴露检验。

## 模型优先级

| 顺序 | 模型 | 用途 |
|---|---|---|
| 1 | 基准 DID | 检验 NAIZ 本地创新质量效应 |
| 2 | DID + 竞争交互项 | 检验 H2 同质化竞争是否削弱 NAIZ 效应 |
| 3 | 距离带宽 / SLX | 检验 H3 周边非 NAIZ 城市是否受到 NAIZ 暴露影响 |
| 4 | SDM | 空间稳健性或补充，不强制作主模型 |

如果 Moran's I 不显著，不必强行使用完整 SDM，可以使用 SLX 或距离带宽模型。

## 权重矩阵候选

| 矩阵 | 含义 | 用途 | 位置 |
|---|---|---|---|
| W1 反距离截断 | 距离越近权重越高，超过阈值为 0 | H3 知识溢出 | 基准 |
| W2 反距离无截断 | 所有城市均有距离衰减关联 | 稳健性 | 稳健性 |
| W3 k 近邻 | 每个城市固定若干最近邻 | 城市密度差异下的稳健性 | 稳健性 |
| W4 Queen 邻接 | 共享边界城市为邻居 | 空间自相关基准 | 补充 |
| W5 时间距离 | 高铁或驾车时间距离 | 交通可达性机制 | 补充 |
| W6 经济距离 | 产业结构越相似权重越高 | H2 竞争 | 稳健性 |
| W7 政策相似度 | 算力券政策越相似权重越高 | H2 机制 | 不作为主权重 |
| W8 复合矩阵 | 地理、经济和政策相似度结合 | 综合稳健性 | 不作为主结果 |

基准空间模型应优先使用纯地理权重或固定距离带宽。政策相似度矩阵只适合作为机制补充，因为政策相似本身可能内生于地方政策竞争、政策学习和中央政策扩散。

## H2：空间竞争模型

H2 的基准不必从 SDM 开始，可以使用竞争暴露交互项：

```text
Y_it = alpha
     + beta * NAIZ_it
     + mu * NAIZ_it * Comp_Intensity_it
     + delta * AI_ExperimentZone_it
     + theta * PolicyControls_it
     + gamma * X_it
     + city FE + year FE + error_it
```

其中 `Comp_Intensity_it` 的基准定义应优先使用：

- 同省其他 NAIZ 城市数量；
- 固定距离带宽内其他 NAIZ 城市数量；
- 固定距离带宽内 AI/ICT 产业结构相似城市数量。

政策文本相似度、补贴比例趋同度和政策相似矩阵用于机制检验或稳健性，不作为唯一主证据。

## H3：空间溢出模型

H3 应优先区分 NAIZ 对非 NAIZ 城市的溢出，而不是把所有城市混在一起。

距离带宽模型：

```text
NonAI_TFP_ict = alpha
              + beta * NAIZ_Exposure_it
              + mu * NAIZ_Exposure_it * NeighborPolicyCompetition_it
              + delta * AI_ExperimentZone_it
              + theta * PolicyControls_it
              + gamma * X_ict
              + city FE + year FE + error_ict
```

SLX 模型：

```text
Y_it = alpha
     + beta * NAIZ_it
     + theta * W_geo * NAIZ_it
     + delta * AI_ExperimentZone_it
     + eta * W_geo * AI_ExperimentZone_it
     + gamma * X_it
     + city FE + year FE + error_it
```

`W_NAIZ` 的解释需区分周边 NAIZ、周边科技部 AI 试验区、周边自贸区等政策叠加，避免把其他政策的空间外溢误认为 NAIZ 溢出。

## SDM 作为空间稳健性

若 Moran's I 和 LM 检验支持完整空间模型，可使用 SDM：

```text
Y_it = rho * W_geo * Y_it
     + beta * NAIZ_it
     + theta * W_geo * NAIZ_it
     + delta * AI_ExperimentZone_it
     + eta * W_geo * AI_ExperimentZone_it
     + gamma * X_it
     + phi * W_geo * X_it
     + city FE + year FE + error_it
```

报告重点应放在直接效应、间接效应和总效应分解，而不是直接解释 `rho`。

## 距离带宽设计

| 带宽 | 含义 | 用途 |
|---|---|---|
| 100 km | 同城化或近距离通勤圈 | 最紧密溢出 |
| 200 km | 高铁约 1 小时圈 | 基准 |
| 300 km | 定期技术交流范围 | 稳健性 |
| 500 km | 跨省合作下限 | 扩展 |

预期 H3 溢出在 100-300 km 内更明显，超过阈值后衰减。

## 需要报告的检验

- Moran's I：因变量是否存在空间自相关。
- LM-lag / LM-error：判断 SAR、SEM 或 SDM 的必要性。
- Wald / LR：判断 SDM 是否可简化。
- Hausman：固定效应和随机效应选择。
- 直接效应、间接效应、总效应分解。

## 实现提醒

- 纯地理权重作为基准，政策相似度矩阵只作为 H2 机制检验。
- 如果 Moran's I 不显著，使用 SLX 或距离带宽模型即可。
- H3 应重点看非 NAIZ 城市；科技部 AI 试验区城市需要排除或单独控制。
- 空间模型不能替代政策边界和变量编码；`NAIZ_it`、`AI_ExperimentZone_it`、`ComputeSubsidy_it` 应分开。
