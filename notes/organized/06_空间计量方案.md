# 空间计量方案

## 为什么需要空间计量

多期 DID 默认一个城市的处理状态不会影响其他城市，但本文的问题本身涉及空间互动：

- NAIZ 城市可能向周边城市产生知识溢出。
- 相邻 NAIZ 城市可能争夺同一批 AI 企业、人才和算力需求。
- 同省或相近城市的算力券政策可能趋同，形成竞争效应。

因此，传统 DID 可以作为基准，但空间 DID、SLX 或 SDM 可以更直接刻画跨城市互动。

## 权重矩阵候选

| 矩阵 | 含义 | 主要用途 |
|---|---|---|
| W1 反距离截断 | 距离越近权重越高，超过阈值为 0 | H3 知识溢出 |
| W2 反距离无截断 | 所有城市均有距离衰减关联 | 稳健性 |
| W3 k 近邻 | 每个城市固定若干最近邻 | 东西部城市密度差异下的稳健性 |
| W4 Queen 邻接 | 共享边界城市为邻居 | 空间自相关基准 |
| W5 时间距离 | 高铁或驾车时间距离 | 补充检验 |
| W6 经济距离 | 产业结构越相似权重越高 | H2 竞争 |
| W7 政策相似度 | 算力券政策越相似权重越高 | H2 核心竞争测度 |
| W8 复合矩阵 | 地理、经济和政策相似度结合 | 综合稳健性 |

## 推荐模型

基准空间模型使用 SDM，因为它同时包含被解释变量空间滞后和解释变量空间滞后：

```text
Y_it = rho * W Y_it
     + beta * NAIZ_it
     + theta * W NAIZ_it
     + gamma * X_it
     + phi * W X_it
     + city FE + year FE + error_it
```

解释重点不应直接放在 `rho`，而应报告直接效应、间接效应和总效应。

## H2 的空间竞争模型

```text
Y_it = beta * NAIZ_it
     + mu * NAIZ_it * (W_comp * NAIZ_it)
     + gamma * X_it
     + city FE + year FE + error_it
```

其中 `W_comp` 可以使用政策相似度、产业结构相似度或地理邻近矩阵。预期 `mu < 0`。

## H3 的空间溢出模型

H3 可以通过距离带宽或空间权重矩阵检验：

- 100 km：同城化或近距离通勤圈。
- 200 km：高铁约 1 小时圈。
- 300 km：技术交流和定期合作的较宽范围。
- 500 km：跨省合作的下限。

预期：溢出效应在 100-300 km 内更明显，超过阈值后衰减。

## 需要报告的检验

- Moran's I：因变量是否存在空间自相关。
- LM-lag / LM-error：判断 SAR、SEM 或 SDM 的必要性。
- Wald / LR：判断 SDM 是否可简化。
- Hausman：固定效应和随机效应选择。
- 直接效应、间接效应、总效应分解。

## 实现提醒

- 基准回归优先使用纯地理权重，降低政策权重或经济权重内生性的批评。
- 政策相似度矩阵适合作为 H2 机制检验，而不是唯一基准。
- 如果 Moran's I 不显著，不必强行使用完整空间模型，可以使用 SLX 检验 `WX` 溢出项。
