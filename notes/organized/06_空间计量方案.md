# 空间计量方案

## 一句话结论

空间计量需要做，但不能变成技术堆砌。本文主空间模型采用 **SLX / 空间暴露 DID**，用于识别邻近 NAIZ 暴露和邻近竞争压力；SDM 只作为稳健性或补充，用于报告直接效应、间接效应和总效应。

正式实证的最小结构为：

```text
Direct NAIZ effect:       NAIZ_it
Spillover effect:         W_NAIZ_it
Competition effect:       NAIZ_it * Comp_it
Distance decay:           W_NAIZ_0_100, W_NAIZ_100_200, W_NAIZ_200_300, W_NAIZ_300_500
Robustness:               SDM direct / indirect / total effects
```

## 为什么普通 DID 不够

普通 DID 通常隐含 no-spillover / SUTVA 假设，即一个城市是否被设为 NAIZ 只影响本城市，不影响其他城市。但本项目不满足这一假设：

| 空间机制 | 在本项目中的含义 | 对普通 DID 的威胁 |
|---|---|---|
| 知识溢出 | NAIZ 城市的 AI 企业、人才、专利知识可能扩散到周边城市 | 对照组被污染，DID 可能低估或误估 |
| 资源竞争 | 邻近城市同时发算力券、建智算中心、抢企业和人才 | 本地政策效应被周边竞争削弱 |
| 政策模仿 | 地方政府相互学习或复制算力补贴政策 | 政策变量不再是孤立冲击 |
| 空间再分配 | NAIZ 可能吸走周边企业、人才和算力需求 | 本地效应不等于区域或全国净效应 |

因此，空间计量的作用不是“模型更高级”，而是区分三类效应：本地 NAIZ 政策效应、邻近知识溢出、邻近同质化竞争。

## 模型优先级

| 顺序 | 模型 | 回答的问题 | 位置 |
|---|---|---|---|
| 1 | 基准 DID | NAIZ 是否提高本地 AI 创新质量 | H1 主模型 |
| 2 | SLX / 空间暴露 DID | 邻近 NAIZ 是否影响本城市结果 | H3 主空间模型 |
| 3 | DID + 竞争交互项 | 周边同质化竞争是否削弱本地 NAIZ 效应 | H2 主模型 |
| 4 | SDM | 在更一般空间依赖结构下结果是否稳健 | 稳健性 |

如果 Moran's I 不显著，不必强行使用 SDM。H2/H3 仍可通过 `W_NAIZ_it`、距离带宽和 `NAIZ_it * Comp_it` 直接检验，因为这些变量对应理论机制，而不仅是残差空间相关修正。

## 主空间模型：SLX / 空间暴露 DID

推荐主空间模型：

```text
Y_it = alpha_i + lambda_t
     + beta * NAIZ_it
     + theta * W_NAIZ_it
     + gamma * X_it
     + delta * W_X_it
     + error_it
```

| 符号 | 含义 |
|---|---|
| `Y_it` | 城市 i 在年份 t 的结果变量，例如 AI 专利质量或非 AI 部门 TFP |
| `NAIZ_it` | 本地 NAIZ 处理状态 |
| `W_NAIZ_it` | 邻近城市 NAIZ 暴露度 |
| `X_it` | 本地控制变量 |
| `W_X_it` | 邻近城市控制变量的空间加权值 |
| `alpha_i` | 城市固定效应 |
| `lambda_t` | 年份固定效应 |

`theta` 是空间暴露效应。若 `theta > 0`，说明邻近 NAIZ 可能产生正向溢出；若 `theta < 0`，可能存在虹吸或资源挤出。

## 权重矩阵优先级

| 权重矩阵 | 用途 | 是否作为基准 |
|---|---|---|
| 200 或 300 km 内反距离矩阵 | 基准空间暴露 | 是 |
| 100 / 200 / 300 / 500 km 距离带 | 检验空间衰减 | 稳健性 |
| k 近邻矩阵 | 缓解东西部城市密度差异 | 稳健性 |
| Queen 邻接矩阵 | 空间自相关诊断 | 补充 |
| 同省矩阵 | 检验省内政策竞争 | H2 补充 |
| 地理距离 × 产业相似度 | 检验产业竞争机制 | H2 机制 |
| 地理距离 × 政策文本相似度 | 检验算力补贴同质化 | H2 机制 |
| 复合矩阵 | 综合稳健性 | 不作为主结果 |

基准必须使用相对外生的地理距离矩阵。产业相似度和政策文本相似度可能受到 AI 基础、政策学习和中央政策扩散影响，因此只放在机制检验或稳健性部分。

## H2：同质化竞争效应

H2 要回答：

> 当周边 NAIZ 或周边算力补贴竞争更强时，本地 NAIZ 对 AI 创新质量的促进效应是否变弱？

推荐模型：

```text
Y_it = alpha_i + lambda_t
     + beta * NAIZ_it
     + mu * NAIZ_it * Comp_it
     + delta * AI_ExperimentZone_it
     + theta * PolicyControls_it
     + gamma * X_it
     + error_it
```

| 系数 | 解释 |
|---|---|
| `beta` | 当竞争强度为 0 时，NAIZ 对本地 AI 创新质量的影响 |
| `mu` | 竞争强度对 NAIZ 效应的调节作用 |
| 预期 | `beta > 0`，`mu < 0` |

`Comp_it` 的替换顺序：

| 顺序 | 竞争变量 | 用途 |
|---|---|---|
| 1 | `Comp_geo_it`：同省或固定距离内其他 NAIZ 城市数量 | 基准，外生性较好 |
| 2 | `Comp_industry_it`：地理邻近 × 政策前产业结构相似 | 产业竞争机制 |
| 3 | `W_ComputeSubsidy_it`：周边算力补贴政策暴露 | 算力补贴竞争机制 |
| 4 | `Comp_policy_it`：地理邻近 × 政策文本或补贴标准相似 | 同质化政策机制，内生性最高 |

不建议把所有空间交互项一次性放入主回归。主文保持简洁，机制部分逐步替换。

## H3：知识溢出效应

H3 要回答：

> NAIZ 城市是否对周边非 NAIZ 城市的非 AI 部门 TFP 产生正向溢出？

全样本 SLX：

```text
NonAI_TFP_it = alpha_i + lambda_t
             + beta * NAIZ_it
             + theta * W_NAIZ_it
             + delta * AI_ExperimentZone_it
             + gamma * X_it
             + error_it
```

仅非 NAIZ 城市样本：

```text
NonAI_TFP_it = alpha_i + lambda_t
             + theta * W_NAIZ_it
             + delta * AI_ExperimentZone_it
             + gamma * X_it
             + error_it
```

仅非 NAIZ 城市样本更适合解释“周边政策暴露”是否改善非处理城市的非 AI 部门 TFP。科技部 AI 试验区城市需要排除或单独控制，否则“非 NAIZ”并不等于“AI 政策空白”。

## 距离衰减检验

将 `W_NAIZ_it` 拆成距离带：

```text
W_NAIZ_0_100_it
W_NAIZ_100_200_it
W_NAIZ_200_300_it
W_NAIZ_300_500_it
```

回归：

```text
NonAI_TFP_it = alpha_i + lambda_t
             + theta1 * W_NAIZ_0_100_it
             + theta2 * W_NAIZ_100_200_it
             + theta3 * W_NAIZ_200_300_it
             + theta4 * W_NAIZ_300_500_it
             + gamma * X_it
             + error_it
```

理论预期是短距离带更强，远距离带逐步减弱。若 `theta1`、`theta2` 为正且显著，而 `theta4` 不显著，更符合知识溢出的地理衰减逻辑。

## 必须做的检验

| 检验 | 做法 | 目的 |
|---|---|---|
| 本地平行趋势 | 事件研究比较 NAIZ 与非 NAIZ 城市政策前趋势 | 支撑 H1 |
| 空间暴露平行趋势 | 比较高 `W_NAIZ_it` 暴露城市与低暴露城市政策前趋势 | 支撑 H3 |
| Moran's I | 检验因变量和基准残差空间自相关 | 判断空间模型必要性 |
| 权重矩阵稳健性 | 替换 100/200/300/500 km、反距离、k 近邻、同省矩阵 | 检验空间结果是否依赖矩阵 |
| Donut 检验 | 剔除 0-100 km，仅使用 100-300 km 暴露 | 排除极近距离同城化或行政边界干扰 |
| 时间 placebo | 将 NAIZ 批复时间提前 2-3 年 | 检查虚假政策效应 |
| 空间 placebo | 随机打乱 NAIZ 城市位置 | 检查空间暴露变量是否机械显著 |
| 非相关结果 | 使用非 AI 专利或低技术专利 | 排除泛化创新冲击 |

## SDM 作为稳健性

若 Moran's I 和 LM 检验支持完整空间模型，可使用 SDM：

```text
Y_it = rho * W_geo * Y_it
     + beta * NAIZ_it
     + theta * W_geo * NAIZ_it
     + delta * AI_ExperimentZone_it
     + eta * W_geo * AI_ExperimentZone_it
     + gamma * X_it
     + phi * W_geo * X_it
     + city FE + year FE + error_it
```

SDM 不作为主因果识别。若使用 SDM，不能只解释 `rho`、`beta`、`theta`，必须报告：

1. 直接效应；
2. 间接效应；
3. 总效应。

原因是加入 `W Y_it` 后，一个城市的政策冲击可能通过空间反馈影响其他城市，再反过来影响自身，系数本身不等于简单边际效应。

## 实现提醒

- 空间变量构造前先确定城市经纬度、城市距离矩阵和样本城市列表。
- `W_NAIZ_it`、`AI_ExperimentZone_it`、`W_AI_ExperimentZone_it` 要分开，避免把其他 AI 政策外溢误认为 NAIZ 外溢。
- `ComputeSubsidy_it` 和 `W_ComputeSubsidy_it` 要与 `NAIZ_it` 分开，因为非 NAIZ 城市也可能出台算力补贴。
- 产业相似度建议用政策前数据构造，例如 2015-2018 年平均值。
- 政策文本相似度只用于机制检验，不作为基准矩阵。
