## 数据补充优先级

为了把项目从“NAIZ DID”升级为“AI 算力政策竞争 + 企业同质化竞争 + 空间外部性”设计，数据工作按以下优先级推进：

| 优先级 | 必须形成的数据 | 目标 |
|---|---|---|
| P0 | `NAIZ_ct`、`AI_ExperimentZone_ct`、AI 专利质量、城市经纬度和距离矩阵 | 能完成 H1 基准、政策混淆控制和最基本空间暴露变量 |
| P1 | `ComputeStack_ct`、`ComputeSupplyIntensity_ct`、`PredictedComputeDemand_ct`、`SupplyExcess_ct` | 能完成 H2：NAIZ 是否伴随政府算力供给侧政策叠加 |
| P1 | `AI_FirmEntry_ct`、`AI_PatentSimilarity_ct`、`LowQualityAIPatentShare_ct`、`AI_TalentCompetition_ct`、`FirmCompetition_ct` | 能完成 H3：企业进入和同质化竞争是否增强 |
| P1 | `Comp_geo_ct`、`Comp_industry_ct`、`W_ComputeStack_ct`、`W_SupplyExcess_ct`、`W_FirmCompetition_ct` | 能完成 H4 和空间竞争扩展 |
| P2 | `Comp_policy_ct`、补贴强度连续变量、政策文本相似度、非 AI 部门 TFP | 能完成机制深化、空间外部性和更高质量稳健性 |
| P2 | 企业规模、所有制、融资约束、政策前 AI 基础、AI 核心企业身份 | 能完成 H5 企业层面分配效应扩展 |

- [ ] 建立 `policy_compute_city_year` 表，逐条记录算力券、模型券、算力补贴和智算中心政策。
- [ ] 建立 `compute_demand_city_year` 表，记录政策前 AI 企业、AI 专利、AI 招聘、数字基础设施和高校 AI 基础。
- [ ] 建立 `firm_competition_city_year` 表，记录 AI 企业进入、专利相似度、低质量 AI 专利占比和 AI 人才竞争。
- [ ] 建立 `firm_panel_ai_patent_year` 表，用于企业层面 H5 扩展和上市公司样本检验。
- [ ] 建立 `distance_matrix_city_pair` 表，记录城市经纬度、球面距离和距离带。
- [ ] 建立 `industry_similarity_city_pair` 表，用政策前产业结构构造城市对相似度。
- [ ] 建立 `patent_ai_firm_city_year` 或 `patent_ai_city_year` 表，保留 AI 专利识别、引用和质量指标所需字段。
- [ ] 建立政策文本原文存档，后续用于政策文本相似度和人工复核。

## 变量构造

- [ ] 将 `NAIZ_ct`、`AI_ExperimentZone_ct`、`ComputeSubsidy_ct`、`ComputeCapacity_ct`、`ComputeStack_ct`、`FirmCompetition_ct` 分开编码。
- [ ] 检查所有与 `NAIZ_ct` 交互的政策 stack，确认其中不包含 `NAIZ_ct` 本身。
- [ ] 构造 `ComputeStack_ct`：算力券、模型券、智算中心、算力补贴等供给侧工具。
- [ ] 构造 `PredictedComputeDemand_ct`：基于政策前 AI 企业、AI 专利、AI 招聘、数字基础设施和高校 AI 基础预测需求。
- [ ] 构造 `SupplyExcess_ct`：算力供给强度相对预测需求基础的过剩代理变量。
- [ ] 构造 `AI_FirmEntry_ct`：AI 企业注册、AI 经营范围企业、AI 子公司或上市公司 AI 业务进入。
- [ ] 构造 `AI_PatentSimilarity_ct` 与 `PatentSimilarity_ijt`：基于 CPC 向量或专利文本向量。
- [ ] 构造 `LowQualityAIPatentShare_ct`：低被引、低新颖性或策略性 AI 专利占比。
- [ ] 构造 `AI_TalentCompetition_ct`：AI 岗位密度、薪酬竞争或岗位关键词相似度。
- [ ] 确定 AI 专利的 CPC/IPC 映射表。
- [ ] 明确 `AI_PatNovelty`、`AI_PatCite`、`AI_PatOrig` 和 `AI_PatGen` 的具体计算公式。
- [ ] 决定机制变量主线：年报 AI 词频、招聘数据、算力补贴或算力能力。
- [ ] 制定算力券政策文本编码表，包括补贴比例、上限、对象、配套措施。
- [ ] 明确非 AI 行业的划分标准。
- [ ] 明确 H4 或空间竞争的基准指标：优先使用同省或固定距离内其他 NAIZ 城市数量，再扩展到周边政策叠加和周边企业竞争。
- [ ] 明确政策文本相似度仅作为机制检验，而非唯一基准指标。

## 实证方法

- [ ] 决定多期 DID 的主估计方法。
- [ ] 设计事件研究图和预趋势检验。
- [ ] 决定是否加入城市线性趋势、省份 × 年份固定效应。
- [ ] 检查是否需要剔除直辖市、省会城市、副省级城市进行稳健性检验。
- [ ] 选择 H4 和空间竞争强度的基准指标和稳健性指标。
- [ ] 检查 NAIZ 后 1-3 年是否伴随算力券、模型券、智算中心和算力补贴政策跟进。
- [ ] 检查 NAIZ 后 1-3 年企业进入、专利技术相似度、低质量 AI 专利和 AI 人才竞争是否增强。
- [ ] 按顺序检验 H4：先做 `NAIZ_ct * ComputeStack_ct`，再做 `NAIZ_ct * FirmCompetition_ct`，最后把三重交互作为强化机制。
- [ ] 选择空间权重矩阵的基准版本，优先使用纯地理权重。
- [ ] 若 Moran's I 不显著，使用 SLX 或距离带宽模型替代完整 SDM。
- [ ] 获取城市经纬度，构造城市间球面距离矩阵。
- [ ] 构造反距离矩阵、固定距离带矩阵、k 近邻矩阵和同省矩阵。
- [ ] 构造 `W_NAIZ_ct`、`Comp_geo_ct`、`Comp_industry_ct`、`Comp_policy_ct` 和距离带空间暴露变量。
- [ ] 构造 `W_ComputeStack_ct`、`W_SupplyExcess_ct`、`W_FirmCompetition_ct`。
- [ ] 检验 `NAIZ_ct` 的平行趋势，也检验高 `W_NAIZ_ct`、高 `W_ComputeStack_ct`、高 `W_FirmCompetition_ct` 暴露城市与低暴露城市的政策前趋势。
- [ ] 设计 donut 检验，例如剔除 0-100 km 后使用 100-300 km 暴露。
- [ ] 设计空间 placebo：随机打乱 NAIZ 城市位置或提前 NAIZ 批复时间。
- [ ] 决定 SDM 是否只作为稳健性，并准备直接效应、间接效应、总效应分解表。
