## 三、NAIZ_spatial_core_plan 的优势

### 1. 更强的经济学理论支撑

NAIZ_plan 明确链接了地点导向政策文献：
- **Kline & Moretti (2014)**：本地效应 vs 空间再分配效应
- **Fajgelbaum & Gaubert (2020)**：最优空间政策框架

这为空间计量提供了**清晰的理论动机**，而不仅仅是技术工具。

### 2. 更清晰的 SUTVA 违背论证

普通 DID 假设：一个城市是否被设为 NAIZ，只影响这个城市自己。

本项目问题不满足此假设：
- NAIZ 城市可能向周边产生知识溢出
- 邻近城市可能争夺同一批 AI 企业和人才
- 地方政府可能模仿算力补贴政策

这种**理论层面的阐述**比单纯说"需要空间计量"更有说服力。

### 3. 更明确的四层递进结构

```
第一层：基准 DID → 本地效应
第二层：空间暴露 DID/SLX → 邻近溢出
第三层：竞争调节模型 → H2 机制
第四层：SDM 稳健性 → 效应分解
```

这种结构**逻辑清晰**，符合学术论文的叙事习惯。

### 4. 更具体的平行趋势检验要求

不仅检验 `NAIZ_it` 的趋势，还要检验 `W_NAIZ_it` 的空间暴露趋势：
```
high exposure city vs low exposure city
```

这是**识别策略的重要补充**，避免空间溢出结果被误解为"趋势差异"。

## 四、项目现有方案（06_空间计量方案）的优势

### 1. 更简洁的模型优先级表格

| 顺序 | 模型 | 用途 |
|---|---|---|
| 1 | 基准 DID | 检验 NAIZ 本地效应 |
| 2 | DID + 竞争交互项 | 检验 H2 |
| 3 | 距离带宽/SLX | 检验 H3 |
| 4 | SDM | 空间稳健性 |

这种**简明的优先级排序**便于实际执行。

### 2. 更明确的变量分离

明确要求区分：
- `NAIZ_it`（工信部先导区）
- `AI_ExperimentZone_it`（科技部试验区）
- `ComputeSubsidy_it`（算力补贴政策）

这避免了之前文献核验中发现的**政策混淆问题**。

### 3. 更具体的实现提醒

- 如果 Moran's I 不显著，使用 SLX 或距离带宽模型即可
- H3 应重点看非 NAIZ 城市
- 科技部 AI 试验区城市需要排除或单独控制

这些**实操性建议**非常宝贵。

## 五、notes_空间权重矩阵方案的独特价值

### 1. 八种矩阵的系统设计

| 矩阵 | 类型 | 用途 |
|---|---|---|
| W1 | 反距离（有截断） | H3 知识溢出基准 |
| W2 | 反距离（无截断） | 稳健性 |
| W3 | k 近邻 | 城市密度差异 |
| W4 | Queen 邻接 | 空间自相关检验 |
| W5 | 时间距离 | 交通可达性机制 |
| W6 | 经济距离（产业相似） | H2 竞争 |
| W7 | 政策相似度 | H2 核心机制 |
| W8 | 嵌套复合 | 综合检验 |

这种**系统化的矩阵设计**提供了丰富的稳健性检验选项。

### 2. 政策相似度矩阵（W7）的详细构造

Step 1: 收集算力券政策文本
Step 2: 提取补贴比例、上限、对象、配套措施
Step 3: 构造政策特征向量
Step 4: 计算余弦相似度或 Jaccard 相似度
Step 5: 与地理距离结合

这为**H2 的机制检验**提供了具体的操作路径。

## 六、融合建议

### 1. 模型框架：采用 NAIZ_plan 的四层结构

```
基准 DID → 空间暴露 DID/SLX → 竞争调节 → SDM 稳健性
```

### 2. 权重矩阵：采用 notes_空间权重矩阵方案

- **基准**：W1（反距离截断 200-300 km）
- **H2 机制**：W7（政策相似度）+ W6（经济距离）
- **稳健性**：W2/W3/W4/W5/W8

### 3. 识别策略：强调 SUTVA 违背和理论机制

参考 NAIZ_plan 的论述，明确说明：
- 为什么普通 DID 的 no-spillover 假设不成立
- 空间计量如何帮助区分本地效应、知识溢出和竞争效应

### 4. 变量处理：保持 06_方案的清晰分离

继续区分 NAIZ、试验区、算力补贴三个政策变量，避免混淆。

### 5. 检验要求：补充空间暴露的平行趋势

参考 NAIZ_plan，不仅检验处理组 vs 对照组，还要检验高暴露城市 vs 低暴露城市的趋势。

## 七、关键判断总结

| 判断维度 | 融合后的结论 |
|---|---|
| **主模型** | DID 基准 + SLX/空间暴露 DID 为主，SDM 仅作为稳健性 |
| **基准权重矩阵** | 纯地理距离（反距离截断 200-300 km） |
| **政策相似度矩阵** | 用于 H2 机制检验，不作为基准 |
| **核心方程** | H2: `Y = α + β·NAIZ + μ·NAIZ×Comp + ...`<br>H3: `NonAI_TFP = α + θ·W_NAIZ + ...` |
| **关键检验** | Moran's I、LM 检验、平行趋势（含空间暴露）、距离衰减、安慰剂 |
